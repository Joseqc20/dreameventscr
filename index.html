Transformamos espacios en recuerdos

Dream Events AMJ nace como un emprendimiento de la pareja Jhoselyn Arias y José Quesada, con el propósito de ofrecer un servicio profesional de decoración para eventos, combinando creatividad, elegancia y atención al detalle. Cada montaje se diseña según el estilo, la temática y el presupuesto de nuestros clientes.

✓

Diseños personalizados: adaptamos colores, temática y elementos decorativos a cada celebración.

✓

Acompañamiento completo: asesoramos desde la idea inicial hasta el montaje final.

✓

Experiencias memorables: creamos espacios listos para disfrutar, celebrar y fotografiar.

Precios básicos de referencia

Cada evento es único. Los siguientes precios son una base para decoraciones sencillas; el costo final se define mediante una cotización personalizada según el tamaño, ubicación, materiales, temática y nivel de personalización.

ServicioPrecio básico desde
Decoración para cumpleaños₡85 000
Decoración para Baby Shower₡95 000
Decoración para graduaciones₡90 000
Decoración para bodas₡250 000
Eventos corporativos₡180 000
Alquiler de letras luminosas₡35 000
Fondo para fotografías₡65 000

Importante

Los precios indicados corresponden a paquetes básicos con decoraciones o productos sencillos. No representan el precio definitivo de un evento personalizado.

Si deseas flores naturales, estructuras especiales, mobiliario adicional, iluminación profesional, temáticas exclusivas, montaje en otra zona o mayor cantidad de elementos decorativos, el precio será ajustado mediante cotización.
